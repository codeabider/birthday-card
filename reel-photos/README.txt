Drop the reel photo here. The reel shows a single slide and tries `01.png`
first (a transparent PNG cutout — e.g. a clipped subject — is preferred), then
falls back to `01.jpg`. If neither exists, the reel shows a generated
placeholder scene instead (the build never breaks).

(This folder is intentionally named reel-photos, NOT final — so it can't
collide with the prerendered /final route on gh-pages.)
